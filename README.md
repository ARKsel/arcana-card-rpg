## ゲーム本体

`ARCANA-source.zip` に公開中のゲームの完全なファイル一式を収録しています。
HTML、JavaScript、CSS、ブラウザ保存機能、カード画像1692枚、背景画像、開発会話ログを含みます。

ZIPをダウンロードして展開し、`dist/index.html` をブラウザで開くと遊べます。
`dist` フォルダの構成を保ったまま利用してください。
